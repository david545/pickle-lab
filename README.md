# Pickle Lab 匹克球擊球動作實驗室

在瀏覽器中分析匹克球擊球動作的單頁網站。上傳擊球影片後，以 MediaPipe Pose 逐幀辨識 33 點骨架，Three.js 呈現 3D 骨架，並與該擊球類型的理想模板對照。

## 功能

- 六種擊球類型，各有獨立的理想模板：正手抽球、反手抽球、發球（低手）、吊小球（dink）、第三拍放短、截擊（volley）
- 3D 骨架與球拍：橘色為實際動作、青色為理想模板，依體型縮放並對齊地面，自動判斷左右手持拍
- 播放：同步播放、暫停、逐格、0.1× 慢放、單次循環、一鍵跳到擊球點
- 數據：擊球點高度（發球腰線檢查）、擊球點前後、引拍幅度、揮拍速度（估計）、膝蓋彎曲、上半身旋轉、頭部位移、分腿墊步時機
- 統計：揮拍疊圖、多拍平均（可排除個別擊球）、瑕疵出現次數
- YouTube 參考影片：並排觀看對照（不做辨識）
- 內建示範資料（每種擊球 6 拍、821 影格、30 fps）

## 使用方式

用 Chrome 或 Edge 開啟 `index.html`，或透過 GitHub Pages 開啟。先選擇擊球類型，再上傳只包含同一種擊球練習的影片。第一次分析時會下載 MediaPipe 模型（約 9 MB）。影片只在本機瀏覽器處理，不會上傳到任何伺服器。

## 拍攝建議

- 120 fps 以上慢動作
- 固定機位，從側面拍攝，全身入鏡
- 避免逆光與畫面中出現其他人

## 限制

- 不追蹤球拍：拍面角度無法判斷，拍速由手腕速度粗估；發球規則中「拍頭低於手腕」無法檢查
- 單鏡頭 3D 推估的深度方向誤差較大
- 理想模板是一般化的教學動作，不代表唯一正確的打法

## 技術

MediaPipe Tasks Vision Pose Landmarker、Three.js r128，單一 HTML 檔，無建置步驟、無後端。
